《永恒之塔2》国际服 · 简繁一键汉化 v2.0.0（英文入口）
制作团队：吃素的佩奇汉化
================================================================

一、这一版是什么
  - 英文入口（游戏默认语言）全量简体 / 繁体汉化
  - 覆盖登录页、选服、技能、道具、任务、外观等全部文本，含 11/11 更新内容
  - 只写两个文件，不改任何 pak、不改字体、不改游戏配置：
      Engine\Content\Localization\Engine\Platforms\Windows\en\Engine.locres
      Engine\Content\Localization\Engine\Platforms\Windows\en-US\Engine.locres
  - 装完直接就是中文，不需要在游戏里改任何语言设置
  - 日文入口不支持本方案：日文走官方 pak 里的文本表，locres 对日文不生效

二、三种使用方式（任选其一）
  1-图形版-双击启动.exe
     窗口里勾选客户端 → 勾选风险确认 →
     点「一键应用【简体中文】」或「一键应用【繁体中文】」→ 直接进游戏

  2-窗口版-安装简体中文.bat
  2-窗口版-安装繁体中文.bat
     命令行窗口版，会自动扫描 Steam / 紫P 客户端，
     有风险提示窗口和多客户端选择窗口

  3-窗口版-还原官方英文.bat
     随时一键还原官方英文

三、安装后
  直接启动游戏即为中文。
  如果还是英文：先在设置里确认文字语言是 English（默认），
  然后完全退出客户端（含 Purple 启动器）重新进一次。

四、还原
  图形版点「一键还原官方英文」，或运行 3-窗口版-还原官方英文.bat。
  原理就是删掉上面那两个 Engine.locres —— 删掉即回落官方英文，
  不需要任何备份，也不会影响游戏更新和 Steam 校验。

五、注意事项
  1. 安装/还原前请完全退出游戏和 Purple 启动器
  2. 修改客户端有风险，请自行评估；本工具完全免费，严禁倒卖
  3. 不碰 pak，游戏更新后这两个文件仍然有效；
     但更新新增的文本会显示英文，等工具更新后重新安装即可
  4. 把游戏切成日文/韩文等其它语言时看不到中文，属正常现象
