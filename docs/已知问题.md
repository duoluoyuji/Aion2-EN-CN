# 已知问题

最后更新：2026-11-12（v2.0.0）

## 1. 登录页底部 4 行英文无法汉化

key：`String_UI_GLOBAL_SERVICE_SERVER_DELAY_TIME_NOTIE_body`

语料里有译文，locres 里也写了这条，但改成测试值后界面毫无变化。
日文入口（整表被替换）可以汉化这 4 行，说明它直接读 `L10NString.dat`，绕过 locres。
不建议为了这 4 行去改 pak。

## 2. 数量单位显示 K

程序固定先除以 1000 再拼单位字符串。把 `K` 改成 `万` 会让 744,175 显示成 `744.1万`（错十倍）。
**决定：保留 K。**

## 3. 只支持英文入口

locres 只在 `en` / `en-US` 这套语言目录下被加载。
实测：把同一份文件放进 `ja` / `ja-JP`，并把存档 `Engine.ini` 的 `Culture` 改成 `ja-JP`，游戏依旧全日本文。
日语、韩语等入口走各自 pak 内的文本表，不适用本方案。

## 4. 条目数与官方表的差额

当前 153,008 条，官方英文表 152,998 个 key。语料源自早期载体字方案，当时因字体缺字有部分条目保留了日文。
补齐只能从游戏提取新增 key 并另行翻译，不能拿日文表拼凑。

## 5. Steam 校验完整性

只还原 pak，不动这两个 locres。想彻底回到英文原版，需要手动删除这两个文件。
