# AION 2 国际服 · 英文入口 简繁汉化

> 只往游戏目录写两个 `Engine.locres` 文件。
> 不改 pak、不改字体、不需要备份；把这两个文件删掉，立刻回落官方英文。

**下载**：[最新版本](../../releases/latest)　**使用说明**：见压缩包内 `0-使用说明（先看这里）.txt`

> 本工具仅适用于**英文客户端**（游戏内语言保持 English）。
> 日文入口不走 locres，不适用本方案。

---

## 这个方案为什么不一样

| | 传统 pak 方案 | 本方案 |
|---|---|---|
| 改了什么 | 替换语言包 pak、替换字体 pak | 只新增两个 locres |
| 字体 | 需要自己拼字形，容易歪、缺字 | 用游戏官方字体，笔画规整 |
| 还原 | 依赖备份，更新后可能还原旧版 | 删文件即可，无需备份 |
| 游戏更新 | 每次都要重新适配整包 | 旧译文继续生效，只需补新增条目 |

原理：UE 在运行时按语言目录加载松散的本地化文件。官方客户端本身不自带任何 locres，所以磁盘上这两个文件就是唯一来源。

```
Aion2\Engine\Content\Localization\Engine\Platforms\Windows\en\Engine.locres
Aion2\Engine\Content\Localization\Engine\Platforms\Windows\en-US\Engine.locres
```

## 支持范围

- 客户端：Steam 国际服、紫P（PURPLE）
- 语言：简体中文 / 繁体中文
- 覆盖：登录页、选服、技能、道具、任务、外观等，共 153,008 条
- 装完直接启动就是中文，**不需要**在游戏里改任何语言设置

---

## 使用方法

**图形版（推荐）**

1. 双击 `1-图形版-双击启动.exe`
2. 勾选检测到的客户端，勾选风险确认
3. 点「一键应用【简体中文】」或「一键应用【繁体中文】」

**窗口版**

```
2-窗口版-安装简体中文.bat
2-窗口版-安装繁体中文.bat
```

没反应或报错时，运行 `4-出问题点这个-生成诊断.bat`，把生成的 txt 发到 Issue。

---

## 还原

点「一键还原官方英文」，或手动删除上面那两条 `Engine.locres`。

删掉即恢复官方英文，没有备份文件残留，也不需要 Steam 校验。

---

## 已知问题

1. 登录页底部有 4 行英文（网络延迟提示）不走 locres，英文入口下无法汉化
2. 数量单位显示为 `K`。程序固定先除以 1000 再拼单位，改成「万」会让数值错十倍，因此保留
3. 只支持英文入口；切到日语、韩语等其它语言不生效
4. 修改客户端可能违反游戏服务条款，风险自担
